# Gemini (Format Asli) - Analisis File

Format permintaan asli Gemini menggunakan struktur Google API. Platform ini mendukung nama parameter Snake_case dan CamelCase, namun **camelCase direkomendasikan** untuk konsistensi.

<Tip>
Gunakan camelCase untuk semua parameter (misalnya `toolConfig` ✅, `tool_config` ❌). Beberapa parameter mungkin tidak dikenali dengan Snake_case.
</Tip>

## Permintaan

<Method method="POST" url="https://kiosapi.com/v1beta/models/{model}:{action}" />

### Parameter Jalur

|Parameter|Wajib|Deskripsi|Contoh|
|-----------|----------|-------------|---------|
|`model`|Ya|Nama model|`gemini-2.5-flash`|
|`action`|Ya|Jenis tindakan|`generateContent` atau `streamGenerateContent?alt=sse`|

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Content-Type`|Ya|`application/json`|
|`x-goog-api-key`| No* |`sk-xxx` (atau gunakan `Authorization: Bearer sk-xxx`)|

<Info>
Anda dapat mengautentikasi dengan header `x-goog-api-key` atau header `Authorization: Bearer`.
</Info>

### Badan Permintaan

|Parameter|Tipe|Wajib|Deskripsi|
|-----------|------|----------|-------------|
|`contents`|array|Ya|Array objek konten|
|`contents[].role`|string|Ya|Peran: `user` atau `model`|
|`contents[].parts`|array|Ya|Array objek bagian|
|`contents[].parts[].text`|string| Tidak |Konten teks|

### Contoh Permintaan - Non-streaming

```bash
curl -X POST "https://kiosapi.com/v1beta/models/gemini-2.5-flash:generateContent" \
  -H "Content-Type: application/json" \
  -H "x-goog-api-key: sk-xxx" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "How are you?"}
        ]
      }
    ]
  }'
```

### Contoh Permintaan - Streaming

```bash
curl -X POST "https://kiosapi.com/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Content-Type: application/json" \
  -H "x-goog-api-key: sk-xxx" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {"text": "How are you?"}
        ]
      }
    ]
  }'
```

### Contoh Python

```python
import requests

url = "https://kiosapi.com/v1beta/models/gemini-2.5-flash:generateContent"
headers = {
    "Content-Type": "application/json",
    "x-goog-api-key": "sk-xxx"
}
data = {
    "contents": [
        {
            "role": "user",
            "parts": [{"text": "How are you?"}]
        }
    ]
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result["choices"][0]["message"]["content"])
```
