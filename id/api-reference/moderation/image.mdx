# Moderasi Gambar

Periksa apakah konten gambar NSFW atau melanggar kebijakan konten.

## Permintaan

<Method method="POST" url="https://kiosapi.com/v1/moderations" />

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Content-Type`|Ya|`application/json`|
|`Authorization`|Ya|`Bearer sk-xxx`|

### Badan Permintaan

|Parameter|Tipe|Wajib|Deskripsi|
|-----------|------|----------|-------------|
|`model`|string|Ya|`gi-image-moderation`|
|`input`|array|Ya|Array objek gambar|
|`input[].type`|string|Ya|Harus `image_url`|
|`input[].image_url.url`|string|Ya|URL gambar atau base64|

### Contoh Permintaan

```bash
curl https://kiosapi.com/v1/moderations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxx" \
  -d '{
    "model": "gi-image-moderation",
    "input": [
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/image.png"
        }
      }
    ]
  }'
```

### Contoh Python

```python
import openai

openai.api_key = "sk-xxx"
openai.base_url = "https://kiosapi.com/v1/"

response = openai.moderations.create(
    model="gi-image-moderation",
    input=[{
        "type": "image_url",
        "image_url": {"url": "https://example.com/image.png"}
    }]
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

### Bidang Kategori

|Kategori|Deskripsi|
|----------|-------------|
|`neutral`|Tidak ada konten seksual|
|`drawings`|Gambar normal, sedikit kemungkinan seksual|
|`sexy`|Konten seksi/provokatif|
|`hentai`|Konten anime dewasa|
|`porn`|Konten seksual eksplisit|
