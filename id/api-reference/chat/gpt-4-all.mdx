# Obrolan - Analisis File gpt-4-semua

`gpt-4-all` mendukung analisis gambar, analisis file, dan kemampuan penelusuran web (berdasarkan inti model gpt-4).

## Fitur

- **Analisis Gambar**: Teruskan URL gambar langsung di `content` untuk menganalisisnya
- **Analisis File**: Meneruskan URL file langsung dalam `content` dengan format: `file_url + space + question`
- **Penjelajahan Web**: Kemampuan pencarian web bawaan

## Permintaan

<Method method="POST" url="https://kiosapi.com/v1/chat/completions" />

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Content-Type`|Ya|`application/json`|
|`Authorization`|Ya|`Bearer sk-xxx`|

### Badan Permintaan

|Parameter|Tipe|Wajib|Deskripsi|
|-----------|------|----------|-------------|
|`model`|string|Ya|`gpt-4-all`|
|`messages`|array|Ya|Array objek pesan|
|`messages[].role`|string|Ya|Peran: `system` atau `user`|
|`messages[].content`|string|Ya|Pertanyaan (dapat menyertakan URL file + spasi + pertanyaan)|
|`temperature`|number| Tidak |Suhu pengambilan sampel (0-2)|
|`stream`|boolean| Tidak |Aktifkan streaming|
|`max_tokens`|number| Tidak |Token maksimum untuk dihasilkan|

### Contoh Permintaan

```bash
curl https://kiosapi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxx" \
  -d '{
    "model": "gpt-4-all",
    "messages": [
      {
        "role": "user",
        "content": "https://example.com/api-doc.pdf What is the API for adding a domain?"
      }
    ],
    "max_tokens": 1688,
    "temperature": 0.5,
    "stream": false
  }'
```

### Contoh Python

```python
import openai

openai.api_key = "sk-xxx"
openai.base_url = "https://kiosapi.com/v1/"

response = openai.chat.completions.create(
    model="gpt-4-all",
    messages=[
        {
            "role": "user",
            "content": "https://example.com/api-doc.pdf What is the API for adding a domain?"
        }
    ],
    max_tokens=1688,
    temperature=0.5,
    stream=False
)

print(response.choices[0].message.content)
```
