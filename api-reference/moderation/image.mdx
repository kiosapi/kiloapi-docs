# Image Moderation

Check if image content is NSFW or violates content policies.

## Request

<Method method="POST" url="https://kiosapi.com/v1/moderations" />

### Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Content-Type` | Yes | `application/json` |
| `Authorization` | Yes | `Bearer sk-xxx` |

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | `gi-image-moderation` |
| `input` | array | Yes | Array of image objects |
| `input[].type` | string | Yes | Must be `image_url` |
| `input[].image_url.url` | string | Yes | Image URL or base64 |

### Example Request

```bash
curl https://kiosapi.com/v1/moderations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxx" \
  -d '{
    "model": "gi-image-moderation",
    "input": [
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/image.png"
        }
      }
    ]
  }'
```

### Python Example

```python
import openai

openai.api_key = "sk-xxx"
openai.base_url = "https://kiosapi.com/v1/"

response = openai.moderations.create(
    model="gi-image-moderation",
    input=[{
        "type": "image_url",
        "image_url": {"url": "https://example.com/image.png"}
    }]
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

### Category Fields

| Category | Description |
|----------|-------------|
| `neutral` | No sexual content |
| `drawings` | Normal image, slight sexual possibility |
| `sexy` | Sexy/provocative content |
| `hentai` | Adult anime content |
| `porn` | Explicit sexual content |
