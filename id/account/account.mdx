# Informasi Akun Kueri

Ambil informasi detail tentang akun KiosAPI Anda.

## Permintaan

<Method method="GET" url="https://kiosapi.com/v1/dashboard/billing/account" />

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Authorization`|Ya|`Bearer sk-xxx`|

### Contoh Permintaan

```bash
curl https://kiosapi.com/v1/dashboard/billing/account \
  -H "Authorization: Bearer sk-xxx"
```

### Contoh Python

```python
import requests

url = "https://kiosapi.com/v1/dashboard/billing/account"
headers = {"Authorization": "Bearer sk-xxx"}

response = requests.get(url, headers=headers)
data = response.json()

print(f"Account ID: {data.get('id')}")
print(f"Balance: ${data.get('balance', 0)}")
```

## Respons

```json
{
  "id": "user-xxx",
  "username": "your-email@example.com",
  "balance": 10.50,
  "used": 3.25,
  "created_at": 1686935002
}
```
