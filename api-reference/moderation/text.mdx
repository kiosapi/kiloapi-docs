# Text Moderation

Check if text content violates usage policies. For detailed usage, see the [OpenAI Moderation Guide](https://platform.openai.com/docs/guides/moderation).

## Request

<Method method="POST" url="https://kiosapi.com/v1/moderations" />

### Headers

| Header | Required | Description |
|--------|----------|-------------|
| `Content-Type` | Yes | `application/json` |
| `Authorization` | Yes | `Bearer sk-xxx` |

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | Moderation model name (e.g. `text-moderation-latest`) |
| `input` | string | Yes | Text content to moderate |

### Example Request

```bash
curl https://kiosapi.com/v1/moderations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxx" \
  -d '{
    "model": "text-moderation-latest",
    "input": "She is very beautiful, I like..."
  }'
```

### Python Example

```python
import openai

openai.api_key = "sk-xxx"
openai.base_url = "https://kiosapi.com/v1/"

response = openai.moderations.create(
    model="text-moderation-latest",
    input="She is very beautiful, I like..."
)

print(response.results[0].flagged)
```
