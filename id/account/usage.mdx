# Penggunaan Token Kueri

Kueri total penggunaan token API Anda. Mendukung pemfilteran rentang tanggal.

## Permintaan

<Method method="GET" url="https://kiosapi.com/v1/dashboard/billing/usage" />

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Authorization`|Ya|`Bearer sk-xxx`|

### Parameter Kueri

|Parameter|Tipe|Wajib|Deskripsi|
|-----------|------|----------|-------------|
|`start_date`|string| Tidak |Stempel waktu mulai (milidetik)|
|`end_date`|string| Tidak |Stempel waktu akhir (milidetik)|

### Contoh Permintaan

```bash
curl "https://kiosapi.com/v1/dashboard/billing/usage?start_date=1716149437000&end_date=1746517437000" \
  -H "Authorization: Bearer sk-xxx"
```

### Contoh Python

```python
import requests

url = "https://kiosapi.com/v1/dashboard/billing/usage"
headers = {"Authorization": "Bearer sk-xxx"}
params = {
    "start_date": "1716149437000",
    "end_date": "1746517437000"
}

response = requests.get(url, headers=headers, params=params)
data = response.json()

# total_usage / 100 = actual usage in USD
actual_usage = data["total_usage"] / 100
print(f"Total usage: ${actual_usage:.2f}")
```

## Respons

```json
{
  "object": "list",
  "total_usage": 695.9646
}
```

<Info>
`total_usage / 100` = jumlah penggunaan sebenarnya. Misalnya, `695.9646 / 100 = $6.96`.
</Info>

### Skema Respons

|Bidang|Tipe|Deskripsi|
|-------|------|-------------|
|`object`|string|Selalu `list`|
|`total_usage`|number|Total pemakaian (bagi 100 dengan jumlah sebenarnya)|
