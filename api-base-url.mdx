# API Base URL

The KiosAPI base URL is:

```
https://kiosapi.com/v1/
```

All API requests should be sent to this address (or the appropriate sub-path for your chosen endpoint format). For example:

| Endpoint | Full URL |
|---|---|
| OpenAI chat completions | `https://kiosapi.com/v1/chat/completions` |
| OpenAI responses | `https://kiosapi.com/v1/responses` |
| Claude native | `https://kiosapi.com/v1/messages` |
| Gemini native | `https://kiosapi.com/v1beta/models/{model}:generateContent` |

## Finding Your Current API Address

While the default base URL is `https://kiosapi.com/v1/`, you should always verify the current API address from your dashboard:

1. Log in to [kiosapi.com](https://kiosapi.com).
2. Navigate to **Dashboard > Console**.
3. Check the displayed API base URL.

<Tip title="Always check the dashboard">
  The API address shown in **Dashboard > Console** is the authoritative source. If the address ever changes, the dashboard will reflect the update first.
</Tip>

## Configuring Your SDK

### OpenAI SDK (Python)

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://kiosapi.com/v1/",
    api_key="sk-kioo-xxxxxxxxxxxx"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

### OpenAI SDK (Node.js)

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://kiosapi.com/v1/",
  apiKey: "sk-kioo-xxxxxxxxxxxx",
});

const response = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "Hello!" }],
});
```

### Anthropic SDK (Python)

```python
import anthropic

client = anthropic.Anthropic(
    base_url="https://kiosapi.com/v1/",
    api_key="sk-kioo-xxxxxxxxxxxx"
)

message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

<Warning title="Bind the correct API URL and KEY">
  A very common mistake is mixing up the **base URL** and **API key**. Here's the rule:

  - ✅ **KiosAPI key** → `https://kiosapi.com/v1/`
  - ❌ KiosAPI key → `https://api.openai.com/v1/` (will fail)
  - ❌ OpenAI key → `https://kiosapi.com/v1/` (will fail)

  Your KiosAPI key only works with the KiosAPI base URL. Double-check both values in your dashboard before debugging authentication errors.
</Warning>

## Environment Variable

You can also set the base URL via an environment variable to avoid hardcoding it:

```bash
# .env
KIOSAPI_BASE_URL=https://kiosapi.com/v1/
KIOSAPI_API_KEY=sk-kioo-xxxxxxxxxxxx
```

<Info title="Why a separate base URL?">
  KiosAPI is designed as a drop-in replacement for OpenAI, Claude, and Gemini APIs. By setting the base URL to `kiosapi.com`, you can use any existing OpenAI-compatible SDK without changing your application logic — just swap the URL and key.
</Info>
