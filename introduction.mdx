# KiosAPI Introduction

KiosAPI is a unified AI API gateway for developers and teams. Use one account and API key to connect applications to supported models through OpenAI-compatible, Anthropic-compatible, and Gemini-compatible interfaces.

<Info>
New to KiosAPI? Complete [Account, Balance, and API Key](/getting-started/register), then follow the [Quickstart](/getting-started/quickstart).
</Info>

## One gateway, multiple API formats

Choose the protocol your existing SDK already expects. You do not need to rewrite an OpenAI integration just to use another supported model family.

| Use case | Recommended format | Endpoint |
|---|---|---|
| OpenAI SDK, Codex, OpenCode, most chat clients | OpenAI compatible | `/v1/chat/completions` or `/v1/responses` |
| Claude Code and Anthropic SDK | Anthropic Messages | `/v1/messages` |
| Google GenAI SDK and Gemini-compatible clients | Gemini native | `/v1beta/models/{model}:generateContent` |

## Addresses to remember

| Purpose | URL | When to use it |
|---|---|---|
| Dashboard | `https://kiosapi.com` | Account, token management, billing, models, and pricing |
| OpenAI API root | `https://kiosapi.com/v1` | OpenAI SDKs and clients that expect an OpenAI-compatible base URL |
| Anthropic Messages | `https://kiosapi.com/v1/messages` | Anthropic SDK and Claude Code configuration |
| Gemini native API root | `https://kiosapi.com/v1beta` | Google GenAI-compatible configuration |

<Warning>
A client may append `/v1` automatically. If your request path becomes `/v1/v1/...`, configure the host as `https://kiosapi.com` instead. See [Configuration Principles](/getting-started/configuration-principles).
</Warning>

## Authentication overview

The key is the same, but the header depends on the protocol.

| Format | Header |
|---|---|
| OpenAI compatible | `Authorization: Bearer sk-xxx` |
| Anthropic Messages | `x-api-key: sk-xxx` plus `anthropic-version: 2023-06-01` |
| Gemini native | `x-goog-api-key: sk-xxx` |

Read [Authentication](/authentication) before integrating a native Anthropic or Gemini client.
