# Kuota Token Kueri

Kueri batas pengeluaran resmi (kuota) untuk token API Anda.

<Info>
Jika token disetel ke "kuota tidak terbatas", hasil kuerinya adalah `100000000`. Ketika kuota token diubah, batasnya terakumulasi di atas jumlah sebelumnya.
</Info>

## Permintaan

<Method method="GET" url="https://kiosapi.com/v1/dashboard/billing/subscription" />

### Header

|Header|Wajib|Deskripsi|
|--------|----------|-------------|
|`Authorization`|Ya|`Bearer sk-xxx`|

### Contoh Permintaan

```bash
curl https://kiosapi.com/v1/dashboard/billing/subscription \
  -H "Authorization: Bearer sk-xxx"
```

### Contoh Python

```python
import requests

url = "https://kiosapi.com/v1/dashboard/billing/subscription"
headers = {"Authorization": "Bearer sk-xxx"}

response = requests.get(url, headers=headers)
data = response.json()

print(f"Hard limit: ${data['hard_limit_usd']}")
print(f"Soft limit: ${data['soft_limit_usd']}")
```

## Respons

```json
{
  "object": "billing_subscription",
  "has_payment_method": true,
  "soft_limit_usd": 5,
  "hard_limit_usd": 5,
  "system_hard_limit_usd": 5,
  "access_until": 0
}
```

### Skema Respons

|Bidang|Tipe|Deskripsi|
|-------|------|-------------|
|`object`|string|Selalu `billing_subscription`|
|`has_payment_method`|boolean|Apakah metode pembayaran ada dalam catatan|
|`soft_limit_usd`|integer|Batas pembelanjaan lunak (USD)|
|`hard_limit_usd`|integer|Batas pembelanjaan keras (USD)|
|`system_hard_limit_usd`|integer|Batas keras tingkat sistem (USD)|
|`access_until`|integer|Akses stempel waktu kedaluwarsa|
